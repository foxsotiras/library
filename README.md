# ИС интеллектуальной библиотеки

Данный репозиторий предназначен для выполнения курсового проекта по дисциплине "Информационные системы и технологии".

Информационная система "Интеллектуальная библиотека" автоматизирует учёт фонда (как печатного, так и электронного), обслуживание читателей и предоставляет новые функции, чтобы вернуть интерес читателей к библиотеке. Объектом автоматизации является муниципальная библиотека, которой пользуются жители города.
